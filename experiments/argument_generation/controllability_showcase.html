Controllable Argument Generation Showcase

How Arguments Are Generated

Arguments are generated using a tree-structured multi-step reasoning process with a fixed depth of 3 reasoning steps.

Generation Process

  1. Tree Search: At each step, a controller explores possible interventions and selects the action(s) at each step
  2. Depth-3 Trajectories: Each argument follows exactly 3 reasoning steps before producing a final synthesized argument
  3. Controllable Interventions: At each step, two types of interventions shape the generation:
    • Structure (10 options): Discourse patterns that determine HOW ideas connect (e.g., "However..." for contrast, "Moreover..." for elaboration)
    • Subtopic (10 options): Argumentative lenses that determine WHAT perspective to take (e.g., cost-benefit analysis, rights & liberties)
  4. Additional Variation: To induce additional diversity in reasoning and final arguments, we included personas (openness, conscientiousness, extraversion, agreeableness, neuroticism) as noted for each argument below

Intervention Mechanism

Each intervention injects guidance into the language model:

  • Prefix Injection: The structure choice adds a literal text prefix (e.g., "Therefore", "However") that the model must continue from
  • Internal Reasoning: The subtopic choice injects guidance into the prompt, steering the model toward a specific argumentative lens

The trajectories below were selected for diversity in structure and subtopic combinations, demonstrating the range of controllable argument styles.
Note that we are using a 'strict synthesis' approach here to emphasize controllability. In practice, one might allow the model greater flexibility when writing the final argument (this poses a control vs quality tradeoff).
This is an early stage demo of capabilities and we are still actively developing this system and exploring optimal approaches.
